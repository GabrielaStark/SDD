# Features de mantenimiento

Guardar cada cambio en una carpeta `docs/features/<slug>/` con requisitos, diseño y tareas según sea necesario. Una intención puede empezar como texto en conversación; intent.md es una ayuda, no un requisito de instalación.

Usar las skills independientes del [catálogo](../../README.md). Aceptan documentos manuales, mantienen aprobación humana entre fases y producen el delta con superficie de contacto e invariantes. No es obligatorio instalar las tres para usar una.
